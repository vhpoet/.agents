# Sign up (Mobile app screens)

A low-friction registration flow that collects only what is needed and sets a positive first impression.

- **Third party sign-up** — Account creation through an existing Apple, Google or social media account, removing the need to set a password
- **Required fields** — The minimum information needed to create an account (typically email and password, if not social auth)
  - Tip: Every additional field reduces completion rate
- **Password strength** — Visual feedback showing how secure the chosen password is as the user types
  - Tip: Showing requirements inline (not only on a submission error) allows users to meet them before submitting
- **Terms and privacy** — The acknowledgement that the user accepts the terms of service and privacy policy before creating an account
- **Email verification** — The step asking users to confirm their email address after the account has been created
  - Tip: It's common to allow the user access to the product before confirming, so they are not blocked and drop off
- **Welcome state** — The screen shown immediately after account creation, confirming success and pointing toward the first action
- **Already have an account** — A link for returning users who arrived at the sign-up screen instead of login
- **Marketing opt-in (if applicable)** — A separate, explicit consent field for users willing to receive marketing emails
