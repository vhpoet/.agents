# Profile (Mobile app screens)

Not the account, but the public-facing identity of a user that others see when they look them up.

- **Profile photo** — An option to set an avatar image, either from the camera roll or by taking a new photo
  - Tip: Offering both options and including a crop step covers the common case where camera photos aren't framed for a circular avatar
- **Display name and/or username** — The name shown publicly and the handle used to identify the account in @mentions or search
  - Tip: If both are editable, make clear which is visible to others and which is used as an identifier
- **Bio** — A short text field where users can describe themselves or their work
  - Tip: Showing a character limit counter as the user approaches it prevents the hard cutoff from feeling unexpected
- **Public fields only** — The screen contains only information visible to other users, private account settings are kept on a separate screen
- **Profile preview** — A read-only view of how the profile will appear to other users, available before saving.
- **External links (if relevant)** — Optional fields for linking to a website, portfolio, or other social accounts
