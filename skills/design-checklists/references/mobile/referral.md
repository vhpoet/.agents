# Referral (Mobile app screens)

The flow through which users earn rewards for introducing new members to the app.

- **Unique referral link or code** — A personalised URL or code that tracks sign-ups back to the referring user that can be copied in one tap
- **Reward explanation** — A clear statement of what the referring user earns and what the new user receives, shown before the user decides whether to share
  - Tip: Showing both sides ('Give a friend one month free, get one month free yourself') is useful
- **Share sheet integration** — A button that opens the native share sheet pre-loaded with the referral link and a suggested message
  - Tip: Pre-fill the message with something that helps the narrative, rather than just a standalone link
- **Channel shortcuts** — Direct share paths for high-performing channels (messaging, email) alongside the generic share sheet
- **Referral status list** — A view showing who the user has referred, whether each person has signed up, and whether the reward condition has been met
- **Reward progress** — A clear display of pending and confirmed rewards, and for tiered programmes, progress toward the next milestone
- **Terms and eligibility** — A concise summary of the conditions under which a referral counts and a reward is earned
  - Tip: Surface the key conditions inline e.g.who qualifies, any limit on total rewards
- **Empty state** — The state of the referral screen before the user has made any referrals, with a clear prompt to begin sharing
