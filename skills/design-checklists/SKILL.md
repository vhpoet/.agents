# Design Checklists Encyclopedia

125 checklists scraped from [checklist.design](https://www.checklist.design) (2026-08-20). Each checklist enumerates what a specific page, screen, component, or flow should contain, with tips.

## How to use

1. Find the page/screen/component/flow being built in the index below. Entries are file slugs.
2. Read only the matching file: `references/<category>/<slug>.md` (each is ~1–2KB). Never read a whole category directory unless auditing that entire area.
3. Treat items as a completeness check, not a mandate — skip items that don't apply to the product, but skip them deliberately.
